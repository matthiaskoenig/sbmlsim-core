# Release notes for sbmlsim-core 0.3.0

sbmlsim-core is a python package on PyPI: `pip install sbmlsim-core` installs the compiler and the engine as one extension, so a model is compiled to `model.wasm` and simulated from python without a build of the repository, and the compiled model runs unchanged in a browser with the JavaScript host of npm. The results of a simulation are the ones of 0.2.0.

## New

- **The python package `sbmlsim-core`** ([#5](https://github.com/matthiaskoenig/sbmlsim-core/pull/5)). `sbmlsim_core.compile_sbml` compiles an SBML model into `model.wasm` and its description `model/2`, `Runtime` loads it and simulates requests of `simulation/1`, one at a time on an `Instance` or as a batch on threads (`LoadedModel.simulate_many`); the errors are `CompileError`, `LoadError` and the errors of a simulation, a failed point of a batch a `PointError` in its position. The package ships `py.typed` and the stub of the extension. The compiler reads SBML Level 3 Version 1 as well as Version 2.
- **Wheels for every platform.** One abi3 wheel for python 3.14 or newer per platform: linux x86_64 and aarch64 (manylinux_2_28), macOS arm64 and x86_64, windows x86_64. Every wheel embeds the same `engine.wasm` and `mathlib.wasm`, built once per release, which the npm package carries as well; every wheel is installed and tested on python 3.14 and 3.15 before anything is published (`.github/workflows/wheels.yml`, also run for every pull request).
- **A build on windows.** The C solvers are compiled with the clang of LLVM for the target of MSVC (`cl` reads neither the GNU attributes of SUNDIALS nor the flags which fix the bits), SUNDIALS profiles with the timers of windows and SuiteSparse is built without a timer, as their CMake builds configure it, which changes no byte of `engine.wasm`. The errors of the C compiler reach the output of cargo.
- **One release for both registries.** A tag `vX.Y.Z` publishes the npm package and the python package with trusted publishing, after the tests of the JavaScript host and of every wheel passed, so both registries get a release or neither.
