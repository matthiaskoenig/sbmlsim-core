# Release notes for sbmlsim-core 0.7.0

A pre-initialization holds the concentration of a species across the initialization, as sbmlsim, roadrunner and PEtab v2 hold it. The results of a simulation whose pre-initialization sets no concentration, or sets one without changing the size of its compartment, are the ones of 0.6.0.

## Fixed

- **A pre-initialized concentration is converted with the size its compartment has once the initial assignments are evaluated** ([#7](https://github.com/matthiaskoenig/sbmlsim-core/issues/7)). A `[S]` of a `preinit` was converted into an amount with the size the compartment has before the initial assignments are evaluated, so the engine disagreed with every other simulator whenever the same pre-initialization changed that size as well, directly or through an initial assignment, and the result depended on the order of the values inside the request. The values which are no concentration are set first, so the initial assignments see them, the initialization runs, every concentration is then converted against the size its compartment has at that point, and the initialization runs again only when something was converted. The order of the values of a request does not matter any more.
