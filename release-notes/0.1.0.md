# Release notes for sbmlsim-core 0.1.0

The first release: an SBML to WebAssembly compiler and a CVODE/KLU simulation engine in Rust, whose JavaScript host is published to npm as the package `sbmlsim-core`. Documentation: https://matthiaskoenig.github.io/sbmlsim-core/.

## The core

- **The compiler** turns a flat SBML Level 3 Version 2 core model into `model.wasm`, with an analytic sparse Jacobian, and its description `model.json` (contract `model/1`); no per-model toolchain is needed. `scripts/prepare_model.py` flattens `comp`, strips the uncertainties of `distrib` and converts other levels.
- **The engine** (`engine.wasm`: Rust with CVODE 7.9 and KLU) runs a request of the contract `simulation/1`: pre-initialization, changes at times (PEtab v2, the semantics of sbmlsim), events with priorities, persistence and delays, a steady state before the start, dense or KLU linear solvers.
- **One wasm everywhere.** wasmtime (the command line `sbmlsim-core`), Node and browsers run the same `engine.wasm`, `mathlib.wasm` and `model.wasm` with bitwise identical results.
- **The SBML Test Suite**: 1581 of 1789 cases pass, every case sbmlsim passes among them; the others are refused at compilation (algebraic rules, the `delay` csymbol, fast reactions).
- **The benchmark**: no model takes more than 2x the time of roadrunner native, dense or with KLU, in wasmtime, Node or Chrome, and every model agrees with roadrunner at tight tolerances.

## The npm package

- `sbmlsim-core` (`loader.mjs`): `createRuntime` and `instantiate` run a compiled model in Node and browsers, without dependencies; the package ships `runtime/engine.wasm` and `runtime/mathlib.wasm` with the notices of their third parties.
- `sbmlsim-core/pool`: a pool of Web Workers (worker threads in Node) with the bits of the main thread; a pool of a module loaded from a CDN starts its workers through a module of the page's origin.
- `sbmlsim-core/panels`: `createPanelEndpoint` answers the routes of the panel service of sbmlsim from the bundle `python -m sbmlsim.serve --export` writes, so an app of panels of sbmlsim-web is a static page whose simulations run in the browser of the reader, e.g. the [glimepiride app](https://matthiaskoenig.github.io/sbmlsim-web/examples/glimepiride/).
- `sbmlsim-core-simulate`: the CSV of a simulation in Node, byte for byte the one of the command line.
